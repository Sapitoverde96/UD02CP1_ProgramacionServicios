# UD02CP1 - Programación de Servicios
El código crea tres hilos con dos parámetros, uno índica que carácter se imprime y el otro cuantas veces se imprime.
Después se ejecutan en paralelo sin sincronización por lo que el orden en que se imprimen los caracteres es 
indeterminado y varía por ejecución. Sin embargo; en este ordenador concreto, parece dar siempre el mismo resultado.
